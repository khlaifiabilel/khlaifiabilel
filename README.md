## Selected Work

Most of my production work lives in private repositories. A representative sample of what I build:

**Sentinel-2 super-resolution.** A radiometrically and spatially consistent super-resolution toolkit for Sentinel-2 imagery, deployed as a horizontally scalable service behind a SentinelHub-style API — FastAPI, GeoServer, S3-backed COGs, and a multi-tenant WMTS tile platform provisioned with Terraform.

**Remote-sensing foundation models.** A crop intelligence foundation model built on MAESTRO for multimodal agricultural remote sensing, plus Sentinel-2 vegetation and land-cover segmentation work.

**Emissions and environmental intelligence.** A methane observation API that ingests satellite-detected plume data and serves GeoJSON and COG endpoints, with GeoServer WMS temporal visualization behind a TerriaJS-based viewer.

**InSAR ground motion.** A Sentinel-1 PSI/SBAS rolling pipeline following the DISP-S1 pattern (COMPASS/ISCE3 + dolphin), CDSE-triggered, producing EGMS-class per-cycle products.

**Water level forecasting.** A Temporal Fusion Transformer for 240-hour water level prediction, served through GPU and CPU FastAPI backends with a React dashboard.

**SAR oil spill detection.** A Sentinel-1 SAR processing pipeline for oil spill detection.
